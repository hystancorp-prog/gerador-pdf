# Hystan

> Transforme planilhas Excel em documentos PDF profissionais em segundos.

**[www.hystan.com.br](https://www.hystan.com.br)**

---

## O que é

Hystan é um SaaS B2C brasileiro que permite a autônomos e pequenos negócios gerar relatórios, orçamentos e recibos em PDF a partir de planilhas Excel — sem formatação manual, sem Word, sem perda de tempo.

## Funcionalidades

- 📊 Planilha Excel → Relatório PDF
- 📋 Gerador de orçamentos com tabela dinâmica
- 🧾 Emissor de recibos com valor por extenso
- 🏢 Cadastro de empresas com logo
- 🌙 Dark / Light / System theme
- 🔐 Autenticação Firebase (Google + email/senha)
- 💳 Pagamentos recorrentes via Stripe
- 📬 Email de boas-vindas automático via Resend

## Stack

| Camada | Tecnologia |
|--------|-----------|
| Backend | Java 17 + Spring Boot 3.5 |
| Banco | PostgreSQL (Railway) |
| Auth | Firebase Auth |
| Pagamentos | Stripe Subscriptions |
| Email | Resend |
